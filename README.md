# CRYPTFALL

Roguelike en primera persona con estética pixel art al estilo *Daggerfall* / *Hexen*. Se juega en el navegador, sin instalar nada.

**▶ Jugar:** https://alexmiauplus01.github.io/HexCrypt/

Entra en mazmorras de varios niveles generadas al azar, saquea cofres, encuentra llaves, enfréntate al Guardián, **sal con vida, con el botín** y hazte cada vez más fuerte para enfrentarte a mazmorras más duras.

| Control | Acción |
|---|---|
| W A S D | Moverse |
| Ratón / Q E | Girar |
| Clic / Espacio | Atacar |
| R · C · V | Habilidades de clase |
| 1 2 3 / rueda | Cambiar de arma |
| I · J · M | Inventario · Diario · Mapa |
| H | Beber poción |
| F · Clic der. | Escudo · Bloquear / esquivar |
| Shift | Esquivar |
| P · N | Pausa y opciones · Sonido |

**Con mando** (Xbox, PlayStation y genéricos) o **en el móvil** (en horizontal): joystick a la izquierda, desliza a la derecha para girar, y botones para atacar, esquivar, habilidades, pausa, diario, inventario y armas.

Encontrarás un **mercader** y un **herrero** en cada mazmorra, **fantasmas rencorosos** de tus personajes caídos, jefes distintos según la zona, y la partida se guarda sola (CONTINUAR en el título).

Caminar contra una pared abre puertas, usa llaves y escaleras, y descubre pasadizos secretos.

---

**English:** a first-person dungeon-crawling roguelike in pixel art, inspired by *Daggerfall* and *Hexen*. Play in your browser (keyboard and mouse, controller or touch), works offline once loaded. Language can be switched in the options.
